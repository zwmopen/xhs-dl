# 万能下载器 v3.6.0 官方正式稳定版发布说明

> **发布日期**：2026-10-01  
> **版本**：v3.6.0 官方正式稳定版  
> **核心突破**：剪贴板极速无感自动采集 ＋ 待下载持久化队列 ＋ 拟人防风控阶梯冷却 ＋ 小红书/抖音双平台无水印直解 ＋ NTFS 原生硬链接归档 ＋ 纯文本轻量通知

---

## 🌟 核心突破与重要特性

### 1. 📋 剪贴板极速无感自动采集（随手复制，后台自动入库）
* **痛点根除**：过去收集爆款图文素材时，用户必须反复“在 App 复制链接 -> 切回下载器窗口 -> 点击粘贴 -> 点击下载 -> 等待完成”，如果连续浏览 10 篇笔记，需要机械重复切换窗口几十次，彻底打断浏览心流。
* **无感秒级捕获**：v3.6.0 引入了轻量级剪贴板守护进程（`universal_clipboard_collector.py`）。只要你在任何聊天工具、浏览器或客户端复制了小红书（`xhslink.cn` / `xiaohongshu.com`）或抖音（`v.douyin.com`）的分享口令或链接，后台会在 **0.1 秒内自动侦测、提取纯净长短链并加入下载队列**，并弹出静默系统通知。你只管连续复制，下载与归档在后台默默完成。
* **零内存污染**：非媒体链接 100% 毫秒级穿透放行，绝不修改、不污染用户的剪贴板原有内容。

---

### 2. 🛡️ 待下载持久化队列与拟人防风控阶梯冷却（保护 IP 与账号）
* **拒绝高频爆破**：连续复制 5 篇链接时，系统绝不会并发请求导致触发平台 IP 风控封锁。所有链接自动进入 `clipboard_pending_queue.json` 持久化队列，单工作协程严格串行处理；
* **拟人随机抖动**：每篇素材下载完成后，自动进入 **8~15 秒随机抖动冷却**，模拟真人浏览节奏；
* **三阶深度冷却退避**：一旦捕获到平台限流或验证码风控，守护进程自动激活阶梯冷却机制（**60秒 -> 120秒 -> 180秒**）。待下载链接 100% 安全暂存在磁盘队列中，冷却倒计时结束后全自动唤醒续跑，一条不漏。

---

### 3. 🌐 小红书 ＋ 抖音双平台深度支持与无水印原画直解
* **双平台自动智能分流**：一段分享文案无论混杂口令、话题还是乱码字符，内核自动正则提取，小红书与抖音走独立专用解析链路；
* **真正无水印原图**：读取平台叠加官方水印前的原始高清图片与无水印视频，按封面、内页顺序自动规范编号，并同步保存包含标题、正文、话题的 `文案.txt`；
* **0 Cookie、0 依赖浏览器登录**：使用临时沙盒会话，不读取、不泄露用户个人浏览器的任何隐私与登录状态。

---

### 4. 🗂️ 智能城市地名分流与 NTFS 原生硬链接（0 额外存储）
* **流量城市自动归档**：下载时通过语义引擎自动提取素材标题与正文中的城市关键词（如宁波、杭州、安吉、金华义乌、台州等），自动落盘至对应城市的规范目录；
* **四季归档 0 空间硬链接**：同卷内自动建立秋季/四季归档的 NTFS 原生硬链接（物理只占一份硬盘空间，却能在多个维度同时检索赏析）；
* **跨卷容灾降级**：若素材存储涉及不同盘符，自动降级为安全软链接或智能副本，绝不静默丢失。

---

### 5. 🔔 极简系统托盘与低扰桌面感知
* **右键托盘大盘感知**：任务栏右下角常驻轻量托盘图标，右键一键直达“素材根目录”、“运行日志”与“查看排队及风控冷却状态”；
* **双段即刻反馈**：复制链接瞬间 0.1s 给予右下角拟态反馈卡片，消除黑盒等待焦虑；
* **飞书大盘协同**：支持将采集进度与作品元数据推送到飞书大盘群，低扰纯文本，不刷屏大图。

---

## 📦 绿色便携版使用指南

1. 从 [最新发布页 (Releases)](https://github.com/zwmopen/xhs-dl/releases/latest) 下载 `universal-downloader-v3.6.0-windows-portable.zip`；
2. 解压到本地任意目录（如 `D:\Tools\万能下载器`）；
3. **两种使用方式任选**：
   * **方式 A：图形界面模式**：双击 `万能下载器.exe`，粘贴链接即可开始采集；
   * **方式 B：极速剪贴板后台守护模式**：运行 `python universal_clipboard_collector.py`（或双击桌面快捷方式），之后在电脑上随手复制小红书/抖音链接，全自动秒级入库！
